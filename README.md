## <img src="https://raw.githubusercontent.com/rosgear/rg-be-partitionbar/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Модуль «Панель разделов»

Модуль входит в состав Панели управления GePanel.

Модуль предоставляет функционал для добавления ссылок на компоненты Панели управления GePanel (модули, расширения модулей, виджеты, плагины) и их систематизации по функциональному назначению в структурированные разделы.

### Скриншот
<img src="https://github.com/rosgear/rg-be-partitionbar/blob/main/assets/help/grid.png?raw=true">

### Установка

Для добавления модуля в ваш проект, вы можете просто выполнить команду ниже:

```
$ composer require rosgear/rg-be-partitionbar
```

или добавить в файл composer.json вашего проекта:
```
"require": {
    "rosgear/rg-be-partitionbar": "*"
}
```
или скачать архив на [странице модуля](https://rosgear.ru/component/rg-be-partitionbar/) в каталоге приложений RosGear.

После добавления модуля в проект выполните его установку в редакцию веб‑приложения с помощью Панели управления GePanel.

## <img src="https://raw.githubusercontent.com/rosgear/rg-be-partitionbar/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Module «Partition Bar»

The module is part of the GePanel Control Panel.

The module provides functionality for adding links to GePanel Control Panel components (modules, module extensions, widgets, plugins) and organizing them by functionality into structured sections.

### Screenshot
<img src="https://github.com/rosgear/rg-be-partitionbar/blob/main/assets/help/grid.png?raw=true">

### Installation

To add the module to your project, you can simply run the command below:

```
$ composer require rosgear/rg-be-partitionbar
```

or add to your project's composer.json file:
```
"require": {
    "rosgear/rg-be-partitionbar": "*"
}
```
or download the archive from the [module page](https://rosgear.ru/component/rg-be-partitionbar/) in the RosGear application catalog.

After adding the module to the project, install it into the web application edition using the GePanel Control Panel.
